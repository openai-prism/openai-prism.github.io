# Paper Tooling Notes

OpenAI Prism is a free LaTeX workspace with unlimited collaborators, unlimited compile time and ChatGPT sitting inside the manuscript. Here is where it stops.

**Read the full page:** https://openai-prism.github.io/

Prism suits research groups writing long-form LaTeX together, especially ones currently losing hours to version conflicts, local TeX installations and slow compile-debug loops. It is a poor fit if your work is not LaTeX, or if institutional policy keeps manuscripts off third-party clouds, because this is a hosted workspace with no local installation by design. The thing to verify for yourself: OpenAI calls it free and lists four separate unlimited entries, so read the current terms rather than assuming that holds forever. For the figures, slides and explainer video that follow a paper, Prism does none of it, and Kyncept generates images and video in the browser.
